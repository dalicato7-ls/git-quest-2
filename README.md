# >_ GIT QUEST · SEASON 2 · Securinets ENIT

> *Hack fast, defend faster.*

Session 2 of the Version Control workshop: team workflows, rewriting history, and trust.
The **Quest Master** bot watches your fork and hands out a flag for every mission:

```
SecurinetsENIT{md5...}
```

## Start

1. **Fork** this repository (keep the name `git-quest-2`, keep "copy the main branch only").
2. **Issues → New issue → Start the Quest**.
3. Do the mission the bot posts, then comment **`/check`**.

## Solo quest

| # | Mission | You'll learn |
|---|---------|--------------|
| 0 | Enlist | fork |
| 1 | Clean Room | `.gitignore`, `git rm --cached` |
| 2 | Keymaster | SSH keys, signed commits |
| 3 | Hotfix | `git stash` |
| 4 | Squash | `git rebase -i` |
| 5 | Surgical Pick | `git cherry-pick` |
| 6 | Ship v1.0.0 | rebase, fast-forward, annotated tags, Releases |

## Team raid

Teams of 3–4 build a repository from the **securinets-enit/git-raid** template and
work like a real team: protected `main`, pull requests, reviews, conflicts, a release.
The captain opens **Issues → New issue → Start the Raid** here.
